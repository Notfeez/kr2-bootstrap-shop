# kr2-bootstrap-shop

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание проекта

Учебный интернет-магазин «ТехноМаг» с каталогом товаров. Сайт состоит из четырёх страниц: главная, каталог, страница товара и форма заявки. Интерфейс собран на Bootstrap 5.3.8 с собственными стилями в `css/custom.css`.

## Используемый фреймворк

Bootstrap 5.3.8.

## Способ подключения Bootstrap

Bootstrap подключён через CDN (jsDelivr):

```html
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css" rel="stylesheet">
<link rel="stylesheet" href="css/custom.css">
...
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
```

Порядок важен: `custom.css` подключается после Bootstrap, чтобы переопределять его стили.

## Реализованные компоненты Bootstrap

Обязательные:
- `container`, `row`, `col-*`, `g-*`, `row-cols-*` (сетка);
- `navbar` (адаптивное меню с бургер-кнопкой на всех страницах);
- `card` (карточки товаров на главной и в каталоге);
- `btn` и варианты `btn-primary`, `btn-outline-primary`, `btn-outline-secondary`, `btn-light`;
- `badge` (статусы «Новинка», «Хит», «Скидка», «Спорт»);
- `alert` (информационные, успешные и предупреждающие сообщения);
- `modal` (быстрый просмотр в каталоге и покупка в один клик на странице товара);
- `form-control`, `form-select`, `input-group`, `form-check`.

Дополнительные:
- `accordion` (доставка и гарантия на странице товара);
- `carousel` (слайдер на главной);
- `pagination` (навигация по страницам каталога);
- `breadcrumb` (хлебные крошки на странице товара);
- `table` (таблица характеристик).

## Самостоятельные доработки

- Каталог с живым поиском, фильтром по категориям и сортировкой по цене (JavaScript, без перезагрузки страницы).
- Модальное окно «Быстрый просмотр», которое заполняется данными из карточки товара через `data-*` атрибуты.
- Проверка формы через Bootstrap-классы `was-validated`, `invalid-feedback` и HTML5-валидацию.
- Собственные стили в `custom.css`: градиентный hero-блок, эффект подъёма карточек при наведении, единое соотношение сторон изображений, адаптивный заголовок, учёт `prefers-reduced-motion`.
- Страница товара с хлебными крошками, таблицей характеристик и аккордеоном.

## Как проверить

1. Открыть `index.html` в браузере.
2. Изменить ширину окна или включить режим адаптивного просмотра в DevTools (F12, Ctrl+Shift+M). Проверить, что карточки перестраиваются: 1 колонка на телефоне, 2 на планшете, 3 на десктопе.
3. Нажать на бургер-кнопку на узком экране: меню должно раскрываться.
4. В каталоге ввести запрос в поиск, выбрать категорию или сортировку. Нажать «Быстрый просмотр», чтобы открыть модальное окно.
5. На странице товара открыть «Купить в один клик» и отправить пустую форму: должна появиться проверка.
6. На странице `order.html` отправить форму без заполнения: поля подсветятся, а после заполнения появится сообщение об успехе.
